# data/sample-docs

本目录用于存放知识摄取样例文档。

当前已落地样例：

- `employee-handbook.txt`
- `employee-handbook.md`
- `policy-catalog.json`
- `sample-policy.pdf`
- `sample-handbook.docx`
- `sample-budget.xlsx`
- `sample-training-deck.pptx`

当前已落地图像预览：

- `sample-budget-preview.png`
- `sample-training-deck-slide-01.png`
- `sample-training-deck-slide-02.png`
- `sample-training-deck-slide-03.png`

V1 必须覆盖的格式：

- `txt`
- `md`
- `json`
- `pdf`
- `docx`
- `xlsx`
- `pptx`

建议每种格式至少准备：

- 1 个结构简单的 happy-path 样例
- 1 个包含表格、列表或复杂结构的边界样例
