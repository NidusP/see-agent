# 单智能体 V1 并行认领板

## 文档控制

- 状态：活动草案
- 版本：`v1.1`
- 目的：为并行会话提供唯一的工作包认领、状态同步与阻塞记录位置

## 1. 更新规则

- 新会话开始并行工作前，先更新本文件，再开始改代码。
- 每个会话只认领一个工作包。
- 进入 `in_progress` 时必须填写 owner、写入范围、最后验证状态和下一步动作。
- 发现跨工作包阻塞时，直接在对应行更新 blocker，不单独散落在聊天记录里。
- 完成或移交时，补齐已验证命令、剩余风险和推荐接手动作。

## 2. 状态枚举

- `unclaimed`
- `in_progress`
- `blocked`
- `handoff_ready`
- `done`
